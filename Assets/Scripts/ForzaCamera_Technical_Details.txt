NEW FEATURES BREAKDOWN:
=======================

1. DYNAMIC HEIGHT SYSTEM:
   - Camera rises smoothly with speed
   - Provides better view at high speeds
   - Forza Horizon trademark feature
   - Uses: baseOffset.y + (speedHeightBonus × speedNormalized)
   - Smoothed with SmoothDamp for natural feel

2. LOOK-AHEAD PREDICTION:
   - Camera anticipates car direction
   - Uses actual velocity vector, not just forward
   - Handles corners and drifts naturally
   - Formula: velocity.normalized × lookAheadAmount × speedFactor × 3
   - Makes camera feel "smart" and anticipatory

3. CORNER TILT (BANKING):
   - Camera rolls/banks during turns
   - Combines angular velocity + steering input
   - Creates cinematic Forza Horizon feel
   - Clamped to maxTiltAngle for realism
   - Applied as roll rotation to final camera orientation

4. DRIFT DETECTION & EFFECTS:
   - Monitors sideways velocity vs forward velocity
   - Calculates slide ratio: sidewaysSpeed / forwardSpeed
   - Triggers when slideRatio exceeds threshold
   - Effects applied:
     * Extra FOV for drama (+5° default)
     * Camera pulls back for better view (+1.5m)
     * Smooth transitions in/out of drift
   - Works automatically with your CarMovement handbrake!

5. COLLISION AVOIDANCE:
   - Raycasts from car to desired camera position
   - If obstacle detected, pulls camera forward
   - Includes padding for safety margin
   - Layer-based filtering for performance
   - Prevents camera clipping through geometry

6. MODULAR ARCHITECTURE:
   - Each system is a separate function
   - Easy to enable/disable features
   - Clean code organization:
     * CalculateDriftFactor()
     * CalculateDynamicOffset()
     * CalculateLookAhead()
     * CalculateCornerTilt()
     * ApplySpeedZoom()
     * PositionAndRotateCamera()
     * ApplyCollisionAvoidance()

CODE IMPROVEMENTS:
==================

SMOOTHING:
----------
All movements use proper damping:
- Position: Vector3.SmoothDamp
- Rotation: Custom Quaternion Slerp with exponential decay
- Floats: Mathf.SmoothDamp / SmoothDampAngle
- Result: Butter-smooth Forza feel

PERFORMANCE:
-----------
- Efficient drift detection (simple math)
- Collision raycast only when enabled
- Cached values prevent recalculation
- Runs in LateUpdate (after physics)

MAINTAINABILITY:
---------------
- Clear variable names with underscore prefix
- Organized in logical sections with headers
- Tooltips on every public parameter
- Comments explain complex calculations
- Debug gizmos for visualization

TECHNICAL SPECIFICATIONS:
=========================

Update Order:
1. Get speed/velocity data
2. Calculate drift factor
3. Calculate dynamic offset
4. Calculate look-ahead
5. Calculate corner tilt
6. Apply FOV zoom
7. Handle manual look
8. Position and rotate camera
9. Apply collision avoidance

Damping Systems:
- Position: ~0.12s smooth time (Forza-tuned)
- Rotation: ~0.15s smooth time
- FOV: ~0.3s smooth time (gentle)
- Height: ~0.4s smooth time (cinematic)
- Tilt: ~0.2s smooth time (responsive)
- Drift: ~0.3s smooth time (dramatic)

Performance Impact:
- Minimal (runs in LateUpdate, 1 raycast max)
- No expensive operations
- Optimized for 60+ FPS
