HIGH-SPEED TRACTION LOSS FIX (v1.1)
===================================

PROBLEM IDENTIFIED:
==================
The car was losing traction at around 100 km/h due to several issues:

1. FRICTION RESET BUG
   - Friction values were being set once at start but not maintained
   - Handbrake mode was modifying friction without proper restoration
   - No dynamic updates during normal driving

2. WEAK DOWNFORCE
   - Downforce calculation was too weak at medium speeds (100-150 km/h)
   - Formula: speed² × 0.01 wasn't aggressive enough
   - Only 2000N base downforce for a 1255kg car at high speeds

3. NO LOAD SENSITIVITY
   - Ferrari_Data has load sensitivity settings (enableLoadSensitivity, optimalLoad)
   - These were not being utilized in CarMovement script
   - Car wasn't adjusting grip based on suspension load

4. WEAK STABILITY AT SPEED
   - Stability control used fixed force multiplier
   - Didn't scale with speed where it matters most

SOLUTIONS IMPLEMENTED:
=====================

? 1. DYNAMIC FRICTION MANAGEMENT
   - New UpdateDynamicFriction() system runs every FixedUpdate
   - Caches base friction values at start (_baseFrictionStiffness, _baseSidewaysStiffness)
   - Applies speed-based grip bonus: 1.0x at low speeds ? 1.25x at 150+ km/h
   - Ensures friction is always properly set (unless handbraking)
   - Properly restores friction after handbrake using cached values

? 2. IMPROVED DOWNFORCE
   - Progressive formula with better medium-speed handling
   - Kicks in at 50 km/h instead of from 0
   - More aggressive multiplier: speed × 0.25 (was speed² × 0.01)
   - Increased base downforce: 3500N (was 2000N)
   - Special attention to 100-150 km/h range where problem occurred

? 3. LOAD-SENSITIVE GRIP SYSTEM
   - New CalculateLoadSensitiveGrip() function
   - Uses Ferrari_Data.enableLoadSensitivity and optimalLoad settings
   - Calculates suspension force on each wheel
   - Optimal load (4200N) = 1.0x grip
   - Under-loaded (airborne/light) = 0.9x grip
   - Over-loaded (heavy cornering) = 0.95x grip
   - Applied via loadSensitivityFactor (0.4 for Ferrari)

? 4. SPEED-SCALED STABILITY CONTROL
   - Stability force now scales with speed
   - 5000N at low speeds ? 12000N at 100+ km/h
   - Ramps up progressively based on speed/100
   - Much stronger where it's needed most

TUNING OPTIONS:
===============
If car still loses traction at speed:
- Increase "Speed Downforce" to 250-350
- Increase "Stability Assist" to 0.6-0.8
- Check Ferrari_Data.optimalLoad (should be 4200N)
- Enable Ferrari_Data.enableLoadSensitivity (should be true)

If car feels too grippy now:
- Decrease "Speed Downforce" to 150-180
- Decrease "Stability Assist" to 0.3-0.4
- Lower Ferrari_Data friction values slightly
